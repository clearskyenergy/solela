Basemap key

Map tiles come from CARTO, which requires a key. One is built into this page and registered for ClearSky's domains, so there is normally nothing to do here. If the map is watermarked “API KEY REQUIRED”, this hostname is not on the registered list — add it at carto.com/basemaps/apikey, or paste a different key below.

Saved in this browser only. For every user to get it, a developer should set window.CS_TILE_KEY in config.js once — but this field is enough to go live.
